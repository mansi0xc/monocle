# Local typography assets

Schibsted Grotesk is used for the wordmark, headings, and interface text. Red Hat Mono is used for digests, byte views, diagnostic codes, and exact integers. Both variable, Latin-subset WOFF2 files are bundled by Vite and served locally; there are no Google Fonts or other third-party font requests at runtime. Uncovered glyphs use the system fallback.

Downloaded from the official Google Fonts CDN on 2026-10-16:

- Schibsted Grotesk (`400–900`): https://fonts.gstatic.com/s/schibstedgrotesk/v7/Jqz55SSPQuCQF3t8uOwiUL-taUTtap9GayojdSFO.woff2
- Red Hat Mono (`300–700`): https://fonts.gstatic.com/s/redhatmono/v16/jVyN7nDnA2uf2zVvFAhhzEsUWOxS3A_geQ.woff2

Catalogs: https://fonts.google.com/specimen/Schibsted+Grotesk and https://fonts.google.com/specimen/Red+Hat+Mono.

The accompanying SIL Open Font License files are copied from the corresponding `ofl/schibstedgrotesk` and `ofl/redhatmono` directories in https://github.com/google/fonts. Retain both license files when redistributing the fonts.
