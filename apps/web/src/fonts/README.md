# Local typography assets

Sora is used for the wordmark and display headings. Public Sans is used for product text and controls. Both variable, Latin-subset WOFF2 files are bundled by Vite and served locally; there are no Google Fonts or other third-party font requests at runtime. Uncovered glyphs use the system fallback.

Downloaded from the official Google Fonts CDN on 2026-10-12:

- Sora (`100–800`): https://fonts.gstatic.com/s/sora/v17/xMQbuFFYT72XzQUpDqW1KX4.woff2
- Public Sans (`100–900`): https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNGfJ7QwOk1.woff2

Catalogs: https://fonts.google.com/specimen/Sora and https://fonts.google.com/specimen/Public+Sans.

The accompanying SIL Open Font License files are copied from the corresponding `ofl/sora` and `ofl/publicsans` directories in https://github.com/google/fonts. Retain both license files when redistributing the fonts.
