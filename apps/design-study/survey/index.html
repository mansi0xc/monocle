Check the arithmetic of finality.

Alpenglow finalizes a block when enough stake signs. Monocle shows that count, vote by vote. It verifies the aggregate signature, qualifies every key and adds the stake in exact integers against a checkpoint you choose. Then it reports which threshold was met, or which check failed.

What happens in a run

  1. Read the bytesParses the bundle within fixed limits and records its SHA-256. A digest identifies the bytes; it does not vouch for their source.
  2. Select the checkpointYou decide which validator set to trust and why. An imported trusted: true grants nothing.
  3. Verify each certificateDecoding, unique signers, key qualification, the aggregate signature, then exact stake. A failure stops the checks that depend on it.
  4. Compose finalityFast and slow paths are evaluated separately and never added together. A lone notarization ends MISSING_FINALIZATION.
  5. Experiment and replayChange one byte, compare fresh reports, export the replay. On import every verdict is recomputed.
